# Arabic RTL Fixer for Affinity Designer/Photo/Publisher

أداة سطح مكتب مجانية لإصلاح النص العربي لأ程序 Affinity التي لا تدعم RTL.

## الميزات

- Always on Top - النافذة تفضل فوق جميع البرامج
- معالجة تلقائية للنص أثناء الكتابة
- ربط الحروف العربية (Arabic Reshaping)
- عكس ترتيب الكلمات للـ RTL
- Dark/Light Theme
- حفظ History آخر 50 نص
- نسخ تلقائي للـ clipboard
- لصق تلقائي في Affinity (Ctrl+Shift+A)
- تظليل النافذة (Opacity slider)
- تصدير النص كملف .txt
- عداد الكلمات والحروف
- حفظ الإعدادات تلقائياً

## التثبيت

### الطريقة الأولى: ملف Python

1. ثبّت [Python 3](https://python.org)
2. حمّل الملفات
3. شغّل `افتحني.bat`

### الطريقة الثانية: ملف EXE

حمّل ملف `Arabic_RTL_Fixer.exe` من Releases وافتحه مباشرة.

## الاختصارات

| الاختصار | الوصف |
|----------|-------|
| Ctrl+Shift+C | نسخ النتيجة |
| Ctrl+L | مسح الكل |
| Ctrl+T | تبديل الثيم |
| Ctrl+Shift+A | لصق في أفينتي |

## متطلبات التشغيل

- Windows 10/11
- Python 3.8+ (لنسخة Python فقط)
- Affinity Designer / Photo / Publisher
